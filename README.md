# StudyApp-DiplomaNet  

Welcome to **StudyApp-DiplomaNet** – an Android app designed to assist students in their studies! 📖✨  
This app provides essential study tools, including **notes, manuals, previous year question papers, a Python compiler, and a chat room with a ChatGPT bot** to enhance the learning experience.

## Features  

### Notes  
- Access a **collection of study materials** organized by subject.  
- **Create, edit, and delete** personal notes.  
- Easily **search and filter** notes.  

### Manual  
- Access a **user manual** to help navigate the app effectively.  
- Find answers to **frequently asked questions**.

### Previous Year Question Papers  
- Access a repository of **previous year exam papers**.  
- Helps with **practice and preparation** for exams.

### Python Compiler  
- Write and run **Python code directly** within the app.  
- Perfect for **programming assignments** and practice.

### Chat Room with ChatGPT Bot  
- **Chat in real-time** with other students.  
- Get **assistance from the ChatGPT bot** for study-related queries.  
- Enhance learning through peer discussions.

## Installation  

To install **StudyApp-DiplomaNet**, follow these steps:  

1. **Clone the repository** to your local machine.
2. **Open the project** in **Android Studio**.
3. **Build and run the app** on an emulator or physical device.
